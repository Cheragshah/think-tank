# Portrait credits

The core twelve seats use the original cartoon portrait set. The newer seats use a real public photo as a fallback avatar until the cartoon pipeline runs. These images are used locally for clearly labeled simulations. Rights remain with the owners.

- Narendra Modi: [Official portrait](https://commons.wikimedia.org/wiki/File:The_official_portrait_of_Shri_Narendra_Modi,_the_Prime_Minister_of_the_Republic_of_India.jpg) via Wikimedia Commons
- Mukesh Ambani: [Mukesh Ambani](https://commons.wikimedia.org/wiki/File:Mukesh_Ambani.jpg) via Wikimedia Commons
- Nikhil Kamath: [Nikhil Kamath at the World Economic Forum](https://commons.wikimedia.org/wiki/File:Nikhil_Kamath_at_World_Economic_Forum.png) via Wikimedia Commons

- Joe Dispenza: official YouTube channel avatar, [@DrJoeDispenza](https://www.youtube.com/@DrJoeDispenza)
- John Demartini: official YouTube channel avatar, [channel](https://www.youtube.com/channel/UC2QloGx6F3YzIVZtgEXA1dQ)

To replace a photo avatar with the original cartoon style, set `KIE_AI_API_KEY` and run `@new-thinker portrait <name>`.
